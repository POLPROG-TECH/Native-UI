# Spacing & Radii

A calm, 4-point grid. Consume via `theme.spacing.md`, the `p="md"` prop on
`Box`, or `gap="md"` on `Stack`.

> **Never hardcode.** If you catch yourself writing `marginTop: 12`, you are
> going off-scale. Use `spacing.md` (= 16) or `spacing.sm` (= 8) instead.

## Spacing scale

| Token | Value | Common use |
|---|---|---|
| `2xs` | **2 px** | Hairline separators, fine border offsets |
| `xs`  | **4 px** | Icon-to-label gap, badge padding |
| `sm`  | **8 px** | List-item vertical rhythm, inline chip gap |
| `md`  | **16 px** | **Default** - card padding, form field gap |
| `lg`  | **24 px** | Section spacing, screen side margin |
| `xl`  | **32 px** | Hero padding, large block separation |
| `2xl` | **40 px** | Landing-page sections |
| `3xl` | **56 px** | Exceptional emphasis only |

</Translated>

# Odstępy i promienie

Spokojna siatka 4-punktowa. Korzystaj z niej przez `theme.spacing.md`, prop
`p="md"` na `Box` albo `gap="md"` na `Stack`.

> **Nigdy nie wpisuj wartości na sztywno.** Jeśli łapiesz się na pisaniu
> `marginTop: 12`, wychodzisz poza skalę. Użyj zamiast tego `spacing.md`
> (= 16) albo `spacing.sm` (= 8).

## Skala odstępów

| Token | Wartość | Typowe zastosowanie |
|---|---|---|
| `2xs` | **2 px** | Cienkie separatory, drobne przesunięcia obramowań |
| `xs`  | **4 px** | Odstęp ikona-etykieta, padding badge |
| `sm`  | **8 px** | Pionowy rytm elementów listy, odstęp między chipami w linii |
| `md`  | **16 px** | **Domyślny** - padding karty, odstęp między polami formularza |
| `lg`  | **24 px** | Odstępy między sekcjami, boczny margines ekranu |
| `xl`  | **32 px** | Padding sekcji hero, oddzielenie dużych bloków |
| `2xl` | **40 px** | Sekcje stron typu landing page |
| `3xl` | **56 px** | Tylko do wyjątkowego wyróżnienia |

## Icon sizes

| Token | Value | Use case |
|---|---|---|
| `sm` | **16 px** | Inline icons in body text, input affixes |
| `md` | **20 px** | Default icon button, list-item lead |
| `lg` | **24 px** | Header bar, tab bar |
| `xl` | **32 px** | Empty states, feature cards |

## Touch targets

Minimum tap target follows platform guidelines:

- **iOS**: `8 px` hitSlop → 44×44 effective target
- **Android**: `10 px` hitSlop → 48×48 effective target

`IconButton` and `Button` apply these automatically; `Pressable` children
should call `hitSlop={theme.hitSlop.ios}` on interactive icons smaller than
the platform minimum.

## Do's & Don'ts

✅ **Do** reach for the closest valid token. If a 12px margin feels right, pick
`sm` (8) or `md` (16) - never introduce `12`.

✅ **Do** scale with `theme.spacing[key]` in StyleSheet when you cannot use
`Box` / `Stack` primitives.

❌ **Don't** mix `padding: 20` with `gap="md"` - the grid breaks as soon as
fonts re-render.

❌ **Don't** hardcode `borderRadius: 12`. Use `radii.sm` (10) or `radii.md`
(14). Visual tolerance is 2 px; users notice anything larger.

## Rozmiary ikon

| Token | Wartość | Zastosowanie |
|---|---|---|
| `sm` | **16 px** | Ikony w tekście, dodatki w polach input |
| `md` | **20 px** | Domyślny przycisk z ikoną, element wiodący w liście |
| `lg` | **24 px** | Pasek nagłówka, pasek kart |
| `xl` | **32 px** | Stany puste, karty funkcji |

## Obszary dotyku

Minimalny obszar dotyku jest zgodny z wytycznymi platform:

- **iOS**: hitSlop `8 px` → efektywny obszar 44×44
- **Android**: hitSlop `10 px` → efektywny obszar 48×48

`IconButton` i `Button` stosują to automatycznie; dzieci `Pressable`
powinny ustawiać `hitSlop={theme.hitSlop.ios}` na interaktywnych ikonach
mniejszych niż minimum platformy.

## Co robić, a czego nie

✅ **Sięgaj** po najbliższy poprawny token. Jeśli margines 12px wydaje się
właściwy, wybierz `sm` (8) albo `md` (16) - nigdy nie wprowadzaj `12`.

✅ **Skaluj** przez `theme.spacing[key]` w StyleSheet, gdy nie możesz użyć
prymitywów `Box` / `Stack`.

❌ **Nie mieszaj** `padding: 20` z `gap="md"` - siatka rozjedzie się, gdy
tylko czcionki się przerenderują.

❌ **Nie wpisuj** na sztywno `borderRadius: 12`. Użyj `radii.sm` (10) albo
`radii.md` (14). Tolerancja wizualna to 2 px; użytkownicy zauważają
większe różnice.
