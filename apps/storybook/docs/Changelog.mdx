# Changelog

All notable changes to **`@polprog/native-ui`** are tracked here and
released via
[Changesets](https://github.com/changesets/changesets). The canonical
source of truth is
[`packages/native-ui/CHANGELOG.md`](https://github.com/POLPROG-TECH/Native-UI/blob/main/packages/native-ui/CHANGELOG.md) -
this page mirrors the recent highlights for in-Storybook reading.

We follow [**Semantic Versioning**](https://semver.org):

- **Major** (`2.0.0`) - breaking API changes. Migration guide mandatory.
- **Minor** (`1.2.0`) - new components, new props, non-breaking changes.
- **Patch** (`1.1.1`) - bug fixes, docs, a11y tweaks, internal refactors.

> **How to upgrade.** Run `npm install @polprog/native-ui@latest` then
> check this page for deprecations and the **Upgrading to 2.0** doc for
> breaking-change recipes. Deprecated APIs are marked `@deprecated` in the
> types, so editors flag them before they are removed.

---

## Unreleased (2.0.0)

Breaking release: removes the 1.x deprecations, raises the peer floor and
changes some visual defaults for accessibility. See **Upgrading to 2.0**.

### Added

- **MSW integration** (`msw@2` + `msw-storybook-addon@2`). Patterns
  stories now run against a mocked `/entries`, `/categories` and
  `/auth/login` backend so Loading / Empty / Error / Slow flows can be
  exercised - and play-tested - without a real server. See
  `Patterns/Network - Loading States` and `Patterns/Network - Forms`.
- **Density stories** for `ListItem` and `SettingsRow` - side-by-side
  `regular` vs `compact` typography density showcases ~12 % vertical
  real-estate recovery on dense screens.
- **Global story toolbars**: `locale` (EN · PL · ES · DE · AR with
  live RTL flip), `fontSize`, `highContrast`, `reduceMotion`. Every
  story gets the a11y matrix for free.
- **Real-device viewports**: iPhone 15 Pro, iPhone 16 Pro Max,
  Pixel 8 Pro, Galaxy S24, iPad Pro 13", Pixel Tablet (plus kept
  legacies for regression screenshots).
- **Docgen union extraction** (`shouldExtractValuesFromUnion: true`) -
  string-union props now render as dropdown controls automatically,
  eliminating manual `argTypes` boilerplate.
- **New stories**: `BottomTabBar`, `Countdown`, `StatTile` - each with
  Playground, AllStates / AllTones, and platform-parity variants.
- **New docs**: `Tokens / Spacing & Radii`, `Patterns / AppShell`, this
  rewritten `Changelog`.
- **Bundle-size gate**: `scripts/check-bundle-size.mjs` enforces
  15 MB / 4 MB / 200 KB budgets as a CI step. Current snapshot:
  **9.41 MB / 15 MB**.

### Changed

- Bulk `action('...')` -> `fn()` migration across 27 story files so
  `play`-tests can assert handler invocations via `args.onX.mock.calls`.
- `preview.tsx` `ThemeCanvas` now adds **20 px of inner padding** by
  default so compact stories don't hug the canvas edge. Opt out per
  story with `parameters.canvasPadding: 0` (used by `HeaderBar`,
  `BottomTabBar`, `ScreenContainer`).
- **Extended play-tests** for `IconButton` (click + disabled),
  `SearchBar` (debounced emission + clear), `Select` (option pick +
  cancel) - each asserts the real `args.onX` spy.
- **Em-dashes (`U+2014`) normalised** to standard hyphens across stories,
  docs and config for consistency with the POLPROG terminal style.

---

## 1.1.0 - 2026-04-20

### Added

- Semantic tokens layer (`useSemantic()` hook + `semantic.colors`,
  `semantic.spacing`, `semantic.typography`) that decouples designer
  intent from raw scheme values.
- New components: `BottomTabBar`, `Countdown`, `StatTile`.
- Chromatic visual regression pipeline + GitHub Pages deploy for every
  push to `main`.

### Changed

- Strict TypeScript mode enabled across the whole library; no `any` or
  implicit return-type leaks.
- ESLint a11y rules (`eslint-plugin-jsx-a11y`) now fail CI at
  `--max-warnings 0`.
- Changesets workflow replaces ad-hoc release notes.
- `Chip`, `Toast`, `HeaderBar`, `Card` surface refinements (tighter
  typography, better shadows in dark mode).

### Fixed

- `PressableScale` no longer animates when `reduceAnimations` is true.
- `BottomSheet` focus trap on Android now restores focus to the opener.

---

## 1.0.0 - 2026-04-18

First stable release.

### Added

- 34 components + 9 primitives covering every screen surface.
- Seven color presets (`default`, `midnight`, `ocean`, `forest`,
  `sunset`, `rose`, `amoled`) with light + dark variants.
- Two typography density presets (`regular`, `compact`).
- Haptic feedback plug-in (`configureHaptics`).
- 188 Jest unit tests, strict TypeScript, 100 % typed public API.

---

## Deprecations

Deprecations land in a minor release, log a one-time warning in dev,
and are removed at the next major.

| Deprecated | Since | Replaced by | Removed in |
|---|---|---|---|
| `typography.amount` / `amountLarge` / `amountSmall` | 1.0.0 | `mono` / `monoLarge` / `monoSmall` | 2.0.0 (removed) |
| `useThemeColors`, Button `destructive`, Card `longPressHint`, Select `selectedValue` / `onValueChange` | 1.x | `useColors`, `danger`, `accessibilityHint`, `value` / `onChange` | 2.0.0 (removed) |
| `Button` `color` prop | 0.9.0 | `variant` | 1.0.0 (already removed) |
| `useTheme().reduceMotion` | 1.1.0 | `useTheme().reduceAnimations` | 2.0.0 (removed) |

---

## Release cadence

- **Patch / Minor** - on demand, typically every 2-3 weeks when enough
  changesets have accumulated.
- **Major** - roughly twice a year, batched with a migration guide +
  a codemod when applicable.
- **Security patches** - out-of-band, within 48 h of disclosure.

---

- **Migration** - step-by-step playbook for upgrading between majors.
- **Getting Started** - install + first-screen checklist.
- **Accessibility** - what each release buys you for WCAG compliance.

# Historia zmian

Wszystkie istotne zmiany w **`@polprog/native-ui`** są zapisywane tutaj i
publikowane za pomocą
[Changesets](https://github.com/changesets/changesets). Kanonicznym
źródłem prawdy jest
[`packages/native-ui/CHANGELOG.md`](https://github.com/POLPROG-TECH/Native-UI/blob/main/packages/native-ui/CHANGELOG.md) -
ta strona powtarza najważniejsze ostatnie zmiany, żeby można je było
przeczytać bez wychodzenia ze Storybooka.

Stosujemy [**wersjonowanie semantyczne (Semantic Versioning)**](https://semver.org):

- **Major** (`2.0.0`) - zmiany API łamiące zgodność. Przewodnik migracji jest obowiązkowy.
- **Minor** (`1.2.0`) - nowe komponenty, nowe propsy, zmiany zachowujące zgodność.
- **Patch** (`1.1.1`) - poprawki błędów, dokumentacja, drobne usprawnienia a11y, wewnętrzne refaktoryzacje.

> **Jak zaktualizować.** Uruchom `npm install @polprog/native-ui@latest`, a
> potem sprawdź na tej stronie przestarzałe API, a w dokumencie
> **Upgrading to 2.0** przepisy na zmiany łamiące zgodność. Przestarzałe API
> są oznaczone w typach jako `@deprecated`, więc edytory sygnalizują je,
> zanim zostaną usunięte.

---

## Niewydane (2.0.0)

Wydanie łamiące zgodność: usuwa przestarzałe API z 1.x, podnosi minimalne
wersje zależności peer i zmienia część domyślnych ustawień wizualnych z
myślą o dostępności. Zobacz **Upgrading to 2.0**.

### Dodane

- **Integracja z MSW** (`msw@2` + `msw-storybook-addon@2`). Stories z sekcji
  Patterns działają teraz na zamockowanym backendzie `/entries`, `/categories`
  i `/auth/login`, więc przepływy Loading / Empty / Error / Slow można
  sprawdzać - także testami play - bez prawdziwego serwera. Zobacz
  `Patterns/Network - Loading States` i `Patterns/Network - Forms`.
- **Stories gęstości** dla `ListItem` i `SettingsRow` - zestawienie obok
  siebie gęstości typografii `regular` i `compact` pokazuje odzyskanie
  ok. 12 % miejsca w pionie na gęstych ekranach.
- **Globalne paski narzędzi stories**: `locale` (EN · PL · ES · DE · AR z
  odwracaniem RTL na żywo), `fontSize`, `highContrast`, `reduceMotion`. Każda
  story dostaje macierz a11y bez dodatkowej pracy.
- **Viewporty prawdziwych urządzeń**: iPhone 15 Pro, iPhone 16 Pro Max,
  Pixel 8 Pro, Galaxy S24, iPad Pro 13", Pixel Tablet (oraz zachowane
  starsze viewporty na potrzeby zrzutów regresyjnych).
- **Wyciąganie wartości unii przez docgen** (`shouldExtractValuesFromUnion: true`) -
  propsy będące uniami stringów są teraz automatycznie renderowane jako
  kontrolki listy rozwijanej, co eliminuje ręczny boilerplate `argTypes`.
- **Nowe stories**: `BottomTabBar`, `Countdown`, `StatTile` - każda z
  wariantami Playground, AllStates / AllTones oraz wariantami zgodności
  między platformami.
- **Nowa dokumentacja**: `Tokens / Spacing & Radii`, `Patterns / AppShell` i
  ten przepisany od nowa `Changelog`.
- **Bramka rozmiaru paczki**: `scripts/check-bundle-size.mjs` pilnuje
  budżetów 15 MB / 4 MB / 200 KB jako krok CI. Aktualny stan:
  **9.41 MB / 15 MB**.

### Zmienione

- Masowa migracja `action('...')` -> `fn()` w 27 plikach stories, dzięki
  której testy `play` mogą sprawdzać wywołania handlerów przez
  `args.onX.mock.calls`.
- `ThemeCanvas` w `preview.tsx` domyślnie dodaje teraz **20 px wewnętrznego
  odstępu**, żeby kompaktowe stories nie przylegały do krawędzi canvasu.
  W danej story można to wyłączyć przez `parameters.canvasPadding: 0`
  (korzystają z tego `HeaderBar`, `BottomTabBar`, `ScreenContainer`).
- **Rozszerzone testy play** dla `IconButton` (kliknięcie + stan wyłączony),
  `SearchBar` (emisja z debounce + czyszczenie), `Select` (wybór opcji +
  anulowanie) - każdy sprawdza prawdziwy spy `args.onX`.
- **Długie myślniki (`U+2014`) znormalizowane** do zwykłych łączników w
  stories, dokumentacji i konfiguracji, dla spójności ze stylem terminala
  POLPROG.

## 1.1.0 - 2026-04-20

### Dodane

- Warstwa tokenów semantycznych (hook `useSemantic()` + `semantic.colors`,
  `semantic.spacing`, `semantic.typography`), która oddziela intencję
  projektanta od surowych wartości schematu kolorów.
- Nowe komponenty: `BottomTabBar`, `Countdown`, `StatTile`.
- Pipeline regresji wizualnej w Chromatic + wdrożenie na GitHub Pages przy
  każdym pushu do `main`.

### Zmienione

- Tryb strict TypeScriptu włączony w całej bibliotece; żadnych `any` ani
  wycieków niejawnych typów zwracanych.
- Reguły a11y ESLint (`eslint-plugin-jsx-a11y`) przerywają teraz CI przy
  `--max-warnings 0`.
- Workflow Changesets zastępuje doraźnie pisane informacje o wydaniach.
- Dopracowane powierzchnie `Chip`, `Toast`, `HeaderBar`, `Card` (ciaśniejsza
  typografia, lepsze cienie w trybie ciemnym).

### Naprawione

- `PressableScale` nie animuje się już, gdy `reduceAnimations` ma wartość true.
- Pułapka fokusu w `BottomSheet` na Androidzie przywraca teraz fokus do
  elementu, który otworzył arkusz.

## Przestarzałe API

Oznaczenie API jako przestarzałego trafia do wydania minor, w trybie dev
jednorazowo wyświetla ostrzeżenie, a samo API znika w kolejnym wydaniu major.

| Przestarzałe | Od wersji | Zastąpione przez | Usunięte w |
|---|---|---|---|
| `typography.amount` / `amountLarge` / `amountSmall` | 1.0.0 | `mono` / `monoLarge` / `monoSmall` | 2.0.0 (usunięte) |
| `useThemeColors`, Button `destructive`, Card `longPressHint`, Select `selectedValue` / `onValueChange` | 1.x | `useColors`, `danger`, `accessibilityHint`, `value` / `onChange` | 2.0.0 (usunięte) |
| Prop `color` w `Button` | 0.9.0 | `variant` | 1.0.0 (już usunięty) |
| `useTheme().reduceMotion` | 1.1.0 | `useTheme().reduceAnimations` | 2.0.0 (usunięte) |
